# CLAUDE.md: 손인식 모듈

사용자가 "시작해"라고 하면 아래를 끝까지 스스로 진행해. 판단이 필요하면 아래 기본값대로 정하고 `docs/decisions.md`에 기록해. 카메라가 없거나 설치가 실패하는 등 진행이 불가능할 때만 물어봐.

## 배경
팀 프로젝트(손동작으로 이미지 속 정답 영역을 지정하는 캡차형 시스템)에서 **손인식 클래스만** 맡았어. 전체 흐름은 이래:

```
문제생성 → 난이도검수 → (자동 검출 실패한 문제만) → 손인식 → 통합
CV 입력(카메라 → frame) ──────────────────────────────↗
```

다른 클래스(문제생성, 난이도검수, 진위검출, CV 입력, 통합)는 팀원이 만들어. 너는 **손인식만** 만들고, 다른 클래스는 테스트용 가짜(mock)로만 써.

- 코드 주석과 문서는 **한국어**. 이 PC는 Windows. Python + OpenCV + MediaPipe.
- 코드는 간단하고 읽기 쉽게. 과한 구조는 만들지 마.

## 인터페이스 (팀 약속, 바꾸지 마)
- **Input**
  - `frame`: 카메라 프레임 (np.ndarray, BGR, CV 입력 클래스가 줌). 손 검출은 이걸로만 해.
  - `problem_img`: **문제 이미지** (np.ndarray, BGR, 1280×720). 사용자가 손으로 정답 영역을 지정하는 이미지.
  - `hint_img`: **힌트 이미지** (np.ndarray, BGR, 크기 자유). 무엇을 찾아야 하는지 알려 주는 작은 이미지.
- **Output**: 현재 손 좌표, 손 상태(status), 손 시리얼 데이터 `np.ndarray` (shape `(N, 2)`, 각 행이 `(x, y)`). 좌표는 모두 **문제 이미지 기준**(0~1279, 0~719).

구현 형태:
```python
tracker = HandTracker(problem_img, hint_img)   # 문제가 바뀌면 새로 만들거나 set_images()로 교체
result = tracker.process(frame)   # 매 프레임 호출
canvas = tracker.render(result)   # 사용자에게 보여 줄 화면 (np.ndarray, BGR)
result.position     # (x, y) 또는 None (손 없음)
result.hand_status  # "none" | "open" | "fist"
result.state        # "idle" | "recording" | "done"
result.trajectory   # np.ndarray (N, 2), 기록 중/완료된 궤적
result.timestamps   # np.ndarray (N,), 각 점의 시각(초). 진위검출용 보조 정보
result.box          # state == "done"일 때 (x1, y1, x2, y2), 아니면 None
tracker.reset()     # 다음 문제를 위해 초기화
```
`result`는 `dataclass` 하나로 만들어.

## 화면 구성과 힌트 이미지 규칙
- 화면(`render`) = 왼쪽에 **문제 이미지(1280×720)**, 오른쪽에 **힌트 패널**(기본 폭 320px, 힌트 이미지를 비율 유지해 축소·가운데 배치, "찾을 대상" 글자 표시).
- **힌트 이미지에는 손이 들어가면 안 돼.**
  - 힌트 패널 위에는 손 커서, 궤적, 카메라 영상 등 **어떤 오버레이도 그리지 마.** 힌트 패널은 항상 원본 그대로 보여야 해.
  - 손 위치가 힌트 패널 쪽(문제 이미지 밖)이면 **무시**: 커서를 그리지 않고, 궤적에 넣지 않고, 기록 시작도 안 돼.
  - 손 좌표 변환은 카메라 프레임 → **문제 이미지 영역(1280×720)에만** 매핑해. 힌트 패널 영역으로는 매핑되지 않게 해.
  - 최종 `box`도 문제 이미지 범위 안으로 잘라(clip).
- 힌트 이미지는 정답 판정이나 손 검출에 쓰지 않아. 보여 주기만 해.
- 원본 `problem_img`, `hint_img` 배열은 수정하지 말고 복사본에 그려.

## 동작 규칙
1. **idle**: 손을 추적만 함. 손이 **주먹(fist)**이 되면 → **recording** 시작, 그 위치를 첫 점으로 기록.
2. **recording**: 매 프레임 손 위치를 궤적에 추가.
3. **종료**: 최근 **1초** 동안 손 이동 범위가 **15픽셀 미만**이면 멈춘 것으로 보고 → **done**. 프레임 수가 아니라 **시간(`time.monotonic()`) 기준**으로 판단.
4. **done**: 궤적과 `box` 반환. `reset()` 전까지 상태 유지.
5. **손을 놓친 경우**: recording 중 손이 **0.5초 이상** 안 보이면 기록 취소하고 idle로 (이유를 문서에 기록).

## 기본값 (생성자 인자로 바꿀 수 있게)
| 항목 | 기본값 |
|---|---|
| 기준 좌표점 | 손바닥 중심 (랜드마크 0, 5, 9, 13, 17 평균) |
| 주먹 판정 | 엄지 제외 네 손가락 중 3개 이상이 접힘 (손가락 끝이 PIP 관절보다 손목에 가까우면 접힘) |
| 멈춤 판정 | 1.0초, 15픽셀 |
| 손 놓침 허용 | 0.5초 |
| 좌표 떨림 보정 | 지수이동평균(EMA), alpha 0.5 |
| 좌표계 | 카메라 프레임 → 문제 이미지 영역(1280×720)으로 변환 |
| 힌트 패널 폭 | 320px |
| 좌우 반전 | `mirror=True` (셀카처럼 보이게) |
| box 규칙 | 궤적 전체를 감싸는 사각형 (x1 < x2, y1 < y2로 정렬) |
| 추적 손 개수 | 1개 |

## 할 일
1. `.venv`, `requirements.txt` (opencv-python, mediapipe, numpy, pytest). 설치된 MediaPipe 버전을 확인하고 동작하는 API(`mp.solutions.hands` 또는 Tasks API `HandLandmarker`)를 골라 버전을 고정해. MediaPipe가 지원하는 Python 버전인지도 확인.
2. `hand_tracker.py`: `HandTracker` 클래스와 결과 dataclass.
3. `demo.py`: 웹캠(`cv2.VideoCapture(0)`)과 샘플 이미지 2장(`samples/problem.png`, `samples/hint.png`, 없으면 코드로 임시 생성)으로 `render` 화면을 띄워. 문제 이미지 위에만 손 커서, 상태, 궤적 선, 완료 시 box를 그려. 카메라 화면은 구석에 작게 띄워도 되지만 **힌트 패널과 겹치면 안 돼.** `r` 리셋, `q` 종료. 카메라가 없으면 안내 메시지 출력.
4. `tests/test_hand_tracker.py`: **카메라 없이** 돌아가는 테스트. MediaPipe 결과 대신 가짜 랜드마크/좌표를 넣어 상태 전환(idle → recording → done), 1초 멈춤 판정, 손 놓침 취소, 좌표 변환, box 계산, **힌트 패널 영역의 손 위치가 무시되는지, render 결과에서 힌트 패널 픽셀이 원본과 똑같은지**를 검증. 이를 위해 랜드마크 → (위치, 상태) 계산 부분과 상태 머신 부분을 분리해서 테스트하기 쉽게 만들어.
5. `README.md`: 설치, 데모 실행법, 인터페이스 설명과 팀원용 사용 예시(통합 클래스에서 어떻게 호출하는지).
6. `docs/decisions.md`: 정한 기준과 이유.

## 마지막에
`pytest` 통과 확인 후, 만든 파일과 인터페이스 요약, 데모에서 사용자가 직접 확인해야 할 것(주먹 인식이 잘 되는지, 멈춤 기준 15픽셀이 적당한지)을 한국어로 짧게 알려 줘.
