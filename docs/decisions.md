# 손인식 모듈 결정 기록

CLAUDE.md의 기본값을 따르고, 지시서에 없던 부분은 아래처럼 정했다.

## 환경
| 항목 | 결정 | 이유 |
|---|---|---|
| Python | 3.12 | PC에 설치된 버전. mediapipe 1.1.1은 3.9~3.14 지원 |
| MediaPipe API | Tasks API `HandLandmarker` (VIDEO 모드) | mediapipe 1.1.1에는 `mp.solutions`가 없음 |
| 모델 전달 | 파일 경로 대신 바이트(`model_asset_buffer`) | Windows에서 MediaPipe(C++)가 한글 경로(`바탕 화면` 등)의 파일을 열지 못함 |
| OpenCV | `opencv-python`과 `opencv-contrib-python`을 같은 버전으로 고정 | mediapipe가 contrib을 함께 설치함. 버전이 다르면 `cv2`가 꼬임 |
| 샘플 이미지 읽기 (데모) | `cv2.imread` 대신 `np.fromfile` + `cv2.imdecode` | Windows에서 `cv2.imread`가 한글 경로를 못 읽음 (실행해서 확인) |
| 한글 글자 | Pillow + 맑은 고딕 | `cv2.putText`는 한글을 못 그림. 폰트가 없으면 영어 "TARGET"으로 대체 |

## 좌표
| 항목 | 결정 | 이유 |
|---|---|---|
| 매핑 | 카메라 정규화 좌표 0~1 → 문제 이미지 0~W-1, 0~H-1 (선형) | 힌트 패널 영역으로는 매핑되지 않게 하려고 |
| 범위 밖 좌표 | 잘라서 붙이지 않고 **무시** (`position=None`) | 카메라 밖으로 걸친 손(정규화 좌표 범위 밖)을 가장자리에 붙이면, 사용자가 의도하지 않은 점이 궤적에 들어감 |
| 무시된 손의 `hand_status` | 실제 손 모양(`open`/`fist`) 그대로 | 손은 보이지만 위치만 쓸 수 없다는 걸 GUI가 구분할 수 있게 |
| EMA 적용 위치 | 문제 이미지 좌표로 바꾼 뒤, 범위 검사 전 | 경계 근처에서 범위 안/밖이 프레임마다 튀는 것을 줄임 |
| EMA 초기화 | 손이 검출되지 않은 프레임에서 | 다시 나타난 손이 예전 위치에서 끌려오지 않게 |

## 커서 기준점, 원본 좌표, 프레임 버퍼 (사용자 요청으로 추가)
| 항목 | 결정 | 이유 |
|---|---|---|
| 커서 기준점 | **검지 끝(랜드마크 8)**. `anchor="palm"`으로 손바닥 중심도 선택 가능 | 사용자 요청. 지시서 기본값(손바닥 중심)과 다름. 손끝이 가리키는 곳이 더 정확함 |
| 주먹을 쥘 때 커서 이동 | 검지를 접으면 검지 끝이 손바닥 쪽으로 내려가 커서가 아래로 조금 이동함 | 검지 끝 기준의 부작용. 기록 첫 점은 주먹을 쥔 뒤의 검지 끝 위치. 데모에서 불편하면 `anchor="palm"` |
| 원본 좌표 `raw_position`, `raw_trajectory` | EMA 적용 전 좌표. `trajectory`와 같은 프레임만 기록해 인덱스로 짝이 맞음 | 사용자 요청. 진위검출에서 미세 떨림을 보려면 보정 전 값이 필요 |
| 원본 좌표 범위 | 이미지 범위로 자름 | 손 무시 여부는 보정본으로 판단하므로, 경계 근처에서 원본만 살짝 밖일 수 있음. 팀 약속(좌표 0~1279, 0~719)을 지키려고 자름 |
| 프레임 버퍼 | 궤적에 점이 기록된 프레임마다 검지 끝 주변 128×128 crop(기본) 또는 1/4 축소본을 시각과 함께 모음 | 사용자 요청. 원본 프레임 전체를 모으면 메모리가 큼 (640×480×3 ≈ 0.9MB/장). crop은 약 48KB/장, 10초 기록이면 약 15MB |
| crop 중심 | 항상 검지 끝 (`anchor`와 무관) | "손끝 주변"이라는 요청. 가장자리는 검정으로 채워 크기를 일정하게 유지 |
| crop 방향 | `mirror=True`면 좌우 반전 | 화면에서 본 손과 같은 방향으로 보이게 |
| 버퍼 전달 시점 | `state == "done"`일 때만 `frames`, `frame_timestamps`로 넘김 | 사용자 요청("선택 확정 시"). 기록 중 매 프레임 리스트를 복사하지 않으려고 |
| 버퍼 길이 | 제한 없음, 취소·`reset()` 때 비움 | 궤적과 같은 규칙. 아주 길게 기록하면 메모리가 늘어나는 점은 주의 |
| 데모 저장 | `frames_날짜_시각.npz`(압축), 경로 CSV에 `raw_x, raw_y` 열 추가 | 결과를 눈으로 확인할 수 있게 |

## 상태 머신
| 항목 | 결정 | 이유 |
|---|---|---|
| 기록 시작 조건 | idle에서 문제 이미지 안의 손이 `fist` | 지시서. 힌트 패널 쪽 주먹은 시작 안 됨 |
| 기록 중 손 모양 | 상관없이 계속 기록 (펴도 됨) | 지시서에 기록 중 조건이 없음. 주먹을 계속 쥐라고 하면 사용자가 지침 |
| 멈춤 판정 시점 | 기록 시작 후 1초가 지나야 판정 | 1초치 기록이 없으면 "1초 동안 멈춤"을 판단할 수 없음 |
| 이동 범위 | 최근 1초 점들의 가로 범위와 세로 범위 중 큰 값 | 단순하고 직관적. 15픽셀 **미만**이면 멈춤 |
| 시간 기준 | `time.monotonic()` | 지시서. 프레임 속도가 달라도 같은 기준 |
| 손 놓침 취소 | recording 중 마지막으로 기록된 점 이후 0.5초 이상 손이 없으면 idle, 궤적 삭제 | 손을 놓친 동안의 이동을 알 수 없어서 궤적이 끊긴 채로 영역을 만들면 실제로 그린 영역과 달라짐. 0.5초 이내는 검출이 잠깐 끊긴 것으로 보고 기록 유지 |
| 문제 이미지 밖의 손 | 손 놓침과 똑같이 처리 (궤적에 안 넣고, 0.5초 넘으면 취소) | 힌트 패널로 손이 간 것은 영역 지정을 그만둔 것과 같음 |
| done 이후 | 궤적·box 고정, `position`/`hand_status`는 계속 갱신 | 지시서("reset 전까지 상태 유지"). 커서는 계속 보여 주는 게 자연스러움 |
| `timestamps` | 기록 시작 시점을 0으로 한 초 | 진위검출에서 쓰기 쉬움. 절대 시각은 의미가 없음 |
| `trajectory` 자료형 | `int32`, EMA 보정된 좌표를 반올림 | 픽셀 좌표라 정수가 자연스러움 |

## box
| 항목 | 결정 | 이유 |
|---|---|---|
| 계산 | 궤적 전체의 최소·최대 (내림/올림) | 지시서 |
| 잘라내기 | 0~W-1, 0~H-1 | 지시서 |
| 폭이나 높이가 0일 때 | 1픽셀로 늘림 (이미지 끝이면 안쪽으로) | `x1 < x2`, `y1 < y2`를 항상 보장 |

## 화면
| 항목 | 결정 | 이유 |
|---|---|---|
| 힌트 패널 | 생성자/`set_images()`에서 한 번 만들어 두고 매번 그대로 붙임 | 손 오버레이가 패널에 섞일 여지를 원천 차단 |
| 패널 배경 | 어두운 회색(40) | 힌트 이미지가 잘 보이게 |
| "찾을 대상" 글자 | 패널 위쪽 60px 영역, 힌트 이미지와 겹치지 않음 | 힌트 이미지는 원본 그대로 보여야 함 |
| 상태 글자 | 문제 이미지 왼쪽 위, 영어 | 매 프레임 그리므로 빠른 `cv2.putText` 사용 |
| 데모 카메라 미리보기 | 문제 이미지 왼쪽 아래 256×144 | 힌트 패널과 겹치지 않게 |
| 궤적 선 | **그리지 않음** (`trajectory`에는 그대로 기록) | 사용자 요청. 지시서의 데모 항목에는 "궤적 선"이 있었지만 이 요청을 우선함 |
| 궤적 길이 | 제한 없음. 기록 시작부터 done까지 모든 점 | 사용자 요청. 진위검출에 전체 경로가 필요 |
| 다시하기 버튼 (데모) | render 화면 **아래**에 60px 버튼 줄을 붙이고 마우스 클릭으로 `reset()` (`r` 키도 유지). 완료되면 버튼이 초록색으로 강조됨 | 사용자 요청. 힌트 패널·문제 이미지와 겹치지 않게 아래에 둠. 버튼은 GUI 담당 몫이라 모듈이 아닌 데모에만 넣음 |
| 멈춘 위치 `stop_position` | done이 될 때 멈춤 판정에 쓴 최근 1초 점들의 평균. `HandResult`에 필드 추가 | 사용자 요청: 움직인 경로와 마지막 멈춘 위치를 따로. 평균을 써서 손떨림에 덜 흔들림. 기존 필드는 그대로 두고 추가만 해서 팀 인터페이스는 깨지지 않음 |
| 완료 표시 | 경로 전체 box 대신 **멈춘 위치**에 초록 원·십자 | 사용자 요청. 경로 전체 box는 실제로 가리킨 곳이 아니라서 화면에서 뺌. `box` 필드 값은 지시서대로 계속 제공 |
| `trajectory` 범위 | 멈춘 1초 구간도 포함한 전체 경로 | 진위검출이 마지막 정지 구간의 떨림도 볼 수 있게. 멈춘 위치는 `stop_position`으로 따로 제공 |
| 저장 (데모) | done이 되면 `recordings/path_날짜_시각.csv` (`t,x,y`)와 `recordings/stop_날짜_시각.csv` (`x,y`)를 따로 저장 | 사용자 요청. 모듈 인터페이스는 그대로 두고 데모에서만 저장 |

## 사용자가 데모로 확인할 것
- 주먹 판정(네 손가락 중 3개 이상 접힘)이 카메라 각도에 따라 잘 되는지
- 멈춤 기준 15픽셀이 너무 빡빡하거나 느슨하지 않은지 (1280×720 기준)
- 주먹을 쥐고 1초 안에 움직이기 시작하지 않으면 바로 done이 되는데, 이게 불편한지
