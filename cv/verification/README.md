# ORB/SIFT 기반 난이도 검수 모듈

문제 이미지에서 검출 대상 이미지를 ORB/SIFT 특징점 매칭으로 찾아, 추정 위치를 사각형 좌표로 반환합니다. 정답 좌표나 정답 마스크를 사용하지 않고 자동 풀이를 시도합니다.

이 모듈은 자동 풀이 결과를 제공하며, 반환된 좌표의 정답 여부 판단과 문제 재생성은 문제 생성 모듈에서 담당합니다.

## 파일 위치

이 README는 `cv/verification/README.md`에 배치하며, 검수 코드 파일 `difficulty_check.py`와 같은 폴더에 둡니다. 아래 사용 예시는 코드 파일명이 `difficulty_check.py`인 경우를 기준으로 합니다.

## 실행 환경

- Python
- NumPy
- OpenCV (`cv2`)

```bash
pip install numpy opencv-python
```

SIFT 모드를 사용하려면 설치된 OpenCV에서 `cv2.SIFT_create`를 지원해야 합니다.

## 사용 방법

### 검수 함수 직접 호출

```python
from cv.verification.difficulty_check import DifficultyCheck

checker = DifficultyCheck()

# image: 문제 이미지 NumPy 배열
# target: 검출 대상 이미지 NumPy 배열
boxes = checker.difficult_check(image, target, method="auto")

for x1, y1, x2, y2 in boxes:
    detected_region = image[y1:y2, x1:x2]
```

위 import 예시는 프로젝트 루트에서 실행하는 경우를 가정합니다. 실행 위치와 프로젝트 패키지 구성에 맞게 import 경로를 조정합니다.

### 문제 생성기와 연결

문제 생성기의 `validator` 인자에 인스턴스의 메서드를 전달합니다. 생성기는 이 콜백을 `validator(image, target)` 형태로 호출할 수 있어야 합니다.

```python
checker = DifficultyCheck()

# ProblemGenerator는 프로젝트의 실제 경로에서 import합니다.
generator = ProblemGenerator(validator=checker.difficult_check)
```

## 입력과 출력

```python
checker.difficult_check(image, target, *, method="auto")
```

| 인자 | 설명 |
| --- | --- |
| `image` | 검출 대상이 포함된 문제 이미지 |
| `target` | 찾으려는 대상 이미지 |
| `method` | `"auto"`, `"orb"`, `"sift"` 중 선택. 기본값은 `"auto"` |

두 이미지는 비어 있지 않은 `np.ndarray`이며, dtype은 `np.uint8`이어야 합니다.

| 이미지 형식 | 배열 형태 |
| --- | --- |
| 흑백 | `(H, W)` |
| BGR | `(H, W, 3)` |
| BGRA | `(H, W, 4)` |

BGR/BGRA 이미지는 흑백으로 변환하여 처리합니다. BGRA **대상 이미지**에서는 알파 값이 0인 픽셀을 제외하고 투명 여백을 자릅니다. 알파 값이 0보다 크면 대상 영역으로 취급합니다. 문제 이미지의 알파 채널은 검출 마스크로 사용하지 않습니다.

반환값은 문제 이미지 좌표계의 `(x1, y1, x2, y2)` 튜플 리스트입니다.

```python
[]                              # 검출 결과 없음
[(100, 80, 180, 160)]            # 박스 1개
[(100, 80, 180, 160), (98, 79, 182, 161)]  # auto에서 두 방법의 좌표가 다른 경우
```

- `(x1, y1)`은 좌상단, `(x2, y2)`는 우하단 끝 좌표입니다.
- `x2`, `y2`는 NumPy 슬라이싱에서 포함되지 않는 끝 좌표입니다.
- 좌표는 문제 이미지 경계 안으로 제한됩니다.
- 각 검출 방법은 최대 1개의 박스를 반환합니다. 현재 `auto` 구현은 ORB와 SIFT의 결과를 합쳐 최대 2개를 반환할 수 있습니다.
- 좌표가 완전히 같은 박스만 중복 제거합니다. 겹치는 박스를 병합하는 NMS는 적용하지 않습니다.

## 검출 모드

| 모드 | 현재 구현의 동작 |
| --- | --- |
| `orb` | ORB로만 검출 |
| `sift` | SIFT로만 검출. SIFT 미지원 시 `RuntimeError` 발생 |
| `auto` | ORB 실행 후 SIFT도 실행하고 결과를 합침. SIFT 미지원 시 ORB 결과만 반환 |

**코드 주석과 현재 동작의 차이:** 메서드 설명에는 “ORB 미검출 시 SIFT 시도”, “최대 한 개의 박스”로 적혀 있지만, 현재 반복문에는 ORB 성공 후 종료하는 처리가 없습니다. 이 문서는 실제 구현을 기준으로 설명합니다.

## 처리 과정

1. **입력 검증 및 전처리**
   - 배열 여부, 빈 이미지 여부, dtype과 채널 수를 검사합니다.
   - 흑백 변환 후 대상의 알파 마스크를 생성합니다.
   - 대상의 투명 여백을 자르고, 마스크 밖 픽셀 값을 0으로 고정합니다.
2. **특징점과 기술자 추출**
   - 대상에는 마스크를 적용하고, 문제 이미지에는 마스크 없이 특징점을 추출합니다.
   - ORB 또는 SIFT로 최대 3,000개의 특징점을 요청합니다.
3. **특징점 매칭**
   - BFMatcher의 KNN 매칭(`k=2`)을 사용합니다.
   - 가장 가까운 매칭 거리가 두 번째 거리의 0.75배 미만인 매칭을 선택합니다.
   - 문제 이미지의 같은 특징점에 연결된 매칭은 거리가 가장 짧은 것만 남깁니다.
4. **위치 추정**
   - RANSAC으로 호모그래피를 계산합니다.
   - 대상 마스크의 외접 사각형을 문제 이미지 좌표계로 변환합니다.
5. **결과 검증 및 반환**
   - 인라이어 수와 비율, 변환 좌표의 유효성, 다각형의 볼록성 및 면적을 검사합니다.
   - 통과한 다각형을 축에 평행한 사각형으로 감싸고 이미지 경계에 맞춰 반환합니다.

## 주요 검출 기준

현재 기준은 코드 내부에 고정되어 있습니다.

| 항목 | 기준 |
| --- | --- |
| ORB 설정 | `nfeatures=3000`, `edgeThreshold=15` |
| SIFT 설정 | `nfeatures=3000` |
| 매칭 거리 | ORB: Hamming / SIFT: L2 |
| 최소 특징점 수 | 대상과 문제 이미지 각각 8개 |
| Ratio test | 최근접 거리 < 두 번째 거리 × 0.75 |
| 최소 유효 매칭 수 | 8개 |
| RANSAC 재투영 오차 임계값 | 4.0픽셀 |
| 최소 인라이어 수 | 6개 |
| 최소 인라이어 비율 | 유효 매칭의 50% |
| 변환 다각형 면적 | 16픽셀² 이상, 문제 이미지 면적 이하 |

호모그래피가 유효하지 않거나, 원근 변환의 무한대 경계를 가로지르거나, 변환 다각형이 볼록하지 않은 경우에도 해당 검출을 거부합니다.

## 예외 및 미검출 처리

| 상황 | 결과 |
| --- | --- |
| 잘못된 입력 타입, 빈 배열, uint8 이외 dtype, 미지원 이미지 형태 | `ValueError` |
| 지원하지 않는 `method` | `ValueError` |
| `sift` 모드에서 SIFT 미지원 | `RuntimeError` |
| 대상의 알파 마스크가 전부 0 | `[]` |
| 특징점·매칭 부족 또는 위치 검증 실패 | 해당 방법의 결과 `[]` |

그 밖의 OpenCV 내부 오류는 호출부로 전달될 수 있습니다.

## 모듈의 역할과 한계

- 검수기는 정답 정보를 받거나 정답과 비교하지 않습니다.
- 문제 재생성, 재시도 및 대기 루프, GUI, 파일 입출력은 담당하지 않습니다.
- 검출 박스가 반환되어도 정답이라는 보장은 없으며, 생성기에서 정답 여부를 판단해야 합니다.
- `[]`는 선택한 알고리즘과 기준으로 검출하지 못했다는 의미입니다. 사람이 풀 수 있는 난이도나 다른 자동 풀이에 대한 저항성을 보장하지 않습니다.
- 특징점이 적거나 반복 무늬가 많고, 가림·변형이 심한 경우 검출 실패 또는 오검출이 발생할 수 있습니다.
- 한 대상의 위치 추정을 위한 구현으로, 같은 대상이 여러 곳에 등장할 때 모든 위치를 찾는 기능은 제공하지 않습니다.
