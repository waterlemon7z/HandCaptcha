## 한 줄 요약
**"진짜 손은 손가락이 제각각 움직이고, 사진은 통째로 움직인다"** — 이걸 규칙과 CNN 두 가지 방법으로 각각 확인해서, 캡차를 푸는 손이 진짜 사람 손인지 판별한다.

---

## 발표 흐름

### 1. 무엇을 막나
- 공격 시나리오: 정답 위치는 AI로 찾고, **손 사진을 그 위치로 움직인 가짜 영상**을 가상 카메라로 넣는 봇
- 원칙: **사람을 봇으로 막지 않는 것**이 우선 (보수적)

### 2. 어떻게 판별하나
손 인식이 끝나면 궤적과 손끝 주변 영상을 받아 3단계로 검사. 하나라도 걸리면 봇.

| 단계 | 보는 것 | 수업 기법 |
|---|---|---|
| 1단계 궤적 | 멈췄을 때 미세한 손 떨림이 있나 | 가우시안 필터 (03) |
| 2단계 영상 ① | 배경에 진짜 카메라 센서 노이즈가 있나 | 프레임 차이 (02-2) |
| 2단계 영상 ②' | **손가락이 따로 움직이나** — 손 위 점들을 추적해 회전·확대·이동 하나로 설명되면 사진 | Harris (04) + 피라미드 LK (03) + 기하 변환 (02-2) |
| 3단계 CNN | 같은 질문을 학습으로 | CNN (05~07) |

- 판단할 데이터가 부족하면 통과 대신 **"다시 해주세요"(재측정)**, 2번 연속이면 실패 → 짧게 움직여 검사를 피하는 봇 차단

### 3. CNN은 어떻게
- 사람 손 데이터가 부족해서, 1300명이 웹캠으로 찍은 손동작 데이터셋 **Jester** 사용
- 진짜 = Jester 손 영상 / 가짜 = 같은 손을 오려 다른 배경 위에서 **같은 경로로** 움직인 영상 (3041쌍)
- 연속 10장을 **채널 10개로 겹쳐** 작은 2D CNN에 입력 → 첫 층부터 시간 변화를 봄
- 모델 구조 (`HandNet`, 직접 설계, 파라미터 29만 개)
  ```
  block(cin, cout) = Conv3×3 → BN → ReLU → Conv3×3 → BN → ReLU → MaxPool2   # 크기 절반
  HandNet = block(10→32) → block(32→64) → block(64→128)        # 64 → 32 → 16 → 8
            → 전역 평균 풀링 → Dropout(0.3) → Linear(128→2)     # [진짜, 가짜] 점수
  ```
  - 크기는 절반씩 줄이고 채널(찾는 무늬 종류)은 늘려서, 뒤로 갈수록 손가락 → 손 전체처럼 넓은 특징을 봄
  - 전역 평균 풀링: 손이 crop 어디에 있든 같은 판단 / Dropout: 외우기(과적합) 방지
- Jester 검증 정확도 **94.8%**

### 4. 결과
| | 사람 89 | 좌표 봇 40 | 합성 영상 봇 64 |
|---|---|---|---|
| 규칙 + CNN | 사람 81 · 재측정 6 · **오판 2** | **40/40 차단** | **64/64 차단** |

- 규칙만으로도 봇 전부 차단, 사람 오판 0
- **CNN은 우리 데이터를 한 번도 안 보고도 합성 봇 92%를 혼자 잡음** → 두 방법이 독립적으로 같은 결론 = 교차 검증

### 5. 한계
- 사람 데이터가 1명(조건만 다양화) / 손가락을 따로 움직이는 3D 렌더링은 뚫릴 수 있음

## 예상 질문 한 줄 답
- **기준값은 어떻게?** 사람과 봇의 특징값을 다 재서, 그 사이에 사람 쪽 여유를 두고 그었다 (②'는 사람 최소의 1/4 지점)
- **CNN 문턱 0.976은?** 진짜 사람 손 296개 중 위에서 1% 지점 = 사람 오판 1% 이하가 되는 값
- **규칙으로 다 잡는데 CNN은 왜?** 같은 단서를 독립된 방법으로 확인하는 교차 검증 + 새 공격 대비
- **MediaPipe 감점 아닌가?** 손끝 위치 찾기에만 쓰고, 판정은 전부 직접 설계한 CV 기법과 CNN
